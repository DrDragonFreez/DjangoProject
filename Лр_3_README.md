# Лабораторная работа № 3 — блог на Django

В проект `DjangoProject` добавлен блог по заданию из пособия: статьи из базы данных, индивидуальная страница статьи, страницы About и Contact, цветная адаптивная навигация Bootstrap. При первом применении миграций база получит четыре демонстрационные статьи.

## Запуск

Из папки `DjangoProject` откройте терминал и выполните:

```powershell
.venv\Scripts\python.exe manage.py migrate
.venv\Scripts\python.exe manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Для редактирования статей перейдите в `/admin/` и войдите под созданной ранее учетной записью администратора.

## Страницы

- `/` — список статей;
- `/article/1/` — отдельная статья;
- `/about/` — описание проекта;
- `/contact/` — контакты;
- `/form/` — форма из предыдущей работы;
- `/admin/` — управление статьями.

Меню сворачивается на узком экране, список статей перестраивается в одну колонку. Bootstrap загружается через CDN, поэтому оформление требует интернет-соединения.
